# Fauna Violet

Путеводитель по животным на Node.js с SQLite, регистрацией по почте и подтверждением одноразовым кодом.

## Запуск

1. Установите Node.js 22 или новее.
2. В папке проекта выполните `npm install`.
3. Запустите `npm start` и откройте `http://localhost:3000`.

Без настроек SMTP сайт включается в режиме разработки: шестизначный код подтверждения показывается в окне регистрации. Не публикуйте этот режим в интернете.

Для отправки настоящих писем задайте переменные окружения перед запуском:

```powershell
$env:SMTP_HOST="smtp.example.com"
$env:SMTP_PORT="587"
$env:SMTP_SECURE="false"
$env:SMTP_USER="your-account"
$env:SMTP_PASS="your-app-password"
$env:SMTP_FROM="Fauna Violet <hello@example.com>"
$env:NODE_ENV="production"
npm start
```

Пользователи хранятся в `fauna.db`. Пароли хешируются через scrypt; проверочные коды действуют 10 минут и допускают до пяти попыток. Для развёртывания за HTTPS включите `NODE_ENV=production`, настройте резервное копирование SQLite и задайте `CODE_PEPPER` уникальным секретом.

## Публикация в интернете

Для Railway подключите проект как GitHub-репозиторий, создайте Volume с mount path `/data`, задайте переменную `DATA_DIR=/data` и сгенерируйте публичный домен. Папка `/data` нужна, чтобы SQLite-база сохранялась между перезапусками. Также добавьте `NODE_ENV=production` и уникальный `CODE_PEPPER`. Для реальных писем задайте SMTP-переменные выше через панель Railway, не добавляя секреты в код или GitHub.

Railway указывает $5 начальных кредитов на первые 30 дней, затем $1/месяц в бесплатном плане плюс возможные расходы сверх включённого потребления. Условия хостинга могут меняться — проверьте страницу тарифов перед запуском.
